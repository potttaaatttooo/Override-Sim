# Assumptions

Structural modelling choices that official sources (the Game Manual, official Q&A) say nothing
about -- what we chose to pretend, not what the rules assert. Empty until simulation work begins
(M6+, per `docs/roadmap.md`). Each future entry: `id`, `statement`, `rationale`, `affects`,
`status: unvalidated | validated | rejected`.

Never mix assumptions into `data/rules/` -- see `CLAUDE.md`, "Hard constraints."
