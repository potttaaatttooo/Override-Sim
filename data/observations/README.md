# Observations

Raw labeled match data (hand-labeled from real match video) -- what we saw, not what we assumed
or measured from it. Empty until the labeling milestone begins (M3, per `docs/roadmap.md`). Each
future record carries `program: v5rc | vexu` (never `both`), `event`, `match_id`, `video_url`,
`labeler`, `label_date`. See `docs/roadmap.md` M3 for the observation schema sketch.
