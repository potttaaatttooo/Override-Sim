# Rules data changelog

Maps each entry in the official Game Manual's own changelog (front matter, "Changelog" section)
to the rule files in this project it forced a change to -- or explicitly records "no model
impact." This is what makes a mid-season manual update a bounded, auditable task instead of a
re-read of the whole manual.

When a new manual version is added (see `docs/roadmap.md`, "Adding a manual version"), append a
new section here before closing out that milestone.

## v1.1 (released 2026-08-06, effective 2026-08-13)

Initial version transcribed into this project. No prior version exists in this repository, so
there is nothing to diff against. The v1.1 manual's own changelog (relative to v1.0) lists
clarifications to `<SC6>`, `<SC7>`, `<SG7>`, `<SG9>`, `<SG10>`, `<SG12>`, `<G1>`/`<G2>`/`<G4>`,
`<GG16>`, `<RSC2>`, `<RSC3b>`, `<R28>`, `<VUG5>`, and the `Midfield` / `Student` definitions --
all already reflected in the v1.1 transcription in `data/rules/override/v1.1/`, since that is the
version transcribed.
